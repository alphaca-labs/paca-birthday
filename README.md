# 🎂 Happy Birthday paca 🦙

paca 생일축하 웹사이트.

## Tech Stack
- Vite + React
- Vanilla CSS (no framework)
- Framer Motion (animations)

## Development
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy
Vercel에서 바로 배포 가능:
- Framework: Vite
- Build Command: `npm run build`
- Output: `dist`
